## 1. VisionLinkとは

VisionLink は、端子台・配線の検査をカメラ画像と AI で支援する Web アプリケーションです。

カメラ画像から YOLO で検査対象を検出し、PaddleOCR で文字を読み取り、あらかじめ用意された検査データと照合します。

主な対象は次の3種類です。

- **Label / nmb**: 端子番号
- **左側 Tube**: 端子左側の線番
- **右側 Tube**: 端子右側の線番

VisionLink は作業者の検査を支援するものであり、AI の表示だけで最終品質を保証するものではありません。

## 2. 検査対象

基本的な1端子の考え方は次のとおりです。

```text
      左側                       右側

   Tube / 線番                Tube / 線番
        │                         │
        ▼                         ▼
   ┌────────┐              ┌────────┐
   │ 左線番 │              │ 右線番 │
   └────────┘              └────────┘
          \                    /
           \                  /
            ┌────────────┐
            │ Label / nmb│
            │   端子番号  │
            └────────────┘
```

端子番号（Label / nmb）を行の基準として、左右に存在する Tube の OCR 結果を対応付けます。

隣接する Label が存在する場合は、その中間位置を境界として各端子の担当範囲を分離します。これにより隣の端子の線番を誤って消し込むことを抑えます。

## 3. 画面の基本構成

検査画面ではカメラ映像、検出BBox、OCR結果、検査結果を確認できます。

主要な操作は次の4つです。

| 操作 | 用途 |
|---|---|
| **L** | 左側 Tube の文字が逆さ（180度）の場合に使用 |
| **Label** | nmb / Label の数字が右へ90度倒れている場合に使用 |
| **Camera** | カメラの開始・停止 |
| **Inspection** | 検査処理の開始・停止 |

ボタン状態によってレイアウトが大きく動かないよう、検査中の主要操作領域は固定配置を基本としています。

## 4. 検査前の準備

1. VisionLink を開きます。
2. 検査対象の製番・検査データを選択します。
3. カメラを対象端子台へ向けます。
4. 端子番号と左右の線番が可能な限り同一画面内に入るようにします。
5. 文字が逆向きの場合は、検査開始前または検査中に `L` / `Label` を適切に設定します。

照明の反射、ピンぼけ、極端な斜め撮影は OCR 精度を低下させます。

## 5. 基本的な検査手順

1. **Camera** を開始します。
2. 画面上の BBox が対象物を正しく囲んでいることを確認します。
3. 必要に応じて **L** または **Label** を ON にします。
4. **Inspection** を開始します。
5. OCR結果と検査結果を確認します。
6. カメラ位置をゆっくり移動し、対象端子を順に検査します。
7. 全対象の結果を確認して検査を終了します。

OCR は複数フレームの結果を利用するため、文字が見えた瞬間にカメラを大きく動かすより、短時間安定して保持する方が読み取りやすくなります。

## 6. L ボタン

`L` は従来の OCR Turn 機能です。

### OFF

- 通常向きの左 Tube クロップ画像を OCR します。
- 通常 BBox は水色系で表示されます。

### ON

- **左側 Tube の OCR 対象クロップ画像を180度回転**して OCR します。
- カメラ映像そのものや検出BBoxの座標を180度回転させる機能ではありません。
- 読取方向を示す表示が対象BBox付近に表示されます。

つまり、`L` は「文字が上下逆さになっている左 Tube を読み取るためのOCR補正」です。

## 7. Label ボタン

`Label` は端子番号（nmb）の向きを補正する機能です。

### OFF

- nmb のクロップ画像をそのまま OCR します。
- BBox は通常の水色系表示です。

### ON

実物上の nmb 数字が **右へ90度（時計回り）倒れている**状態を対象とします。

```text
実物の文字
   ↓
右へ90度倒れている
   ↓
OCR用クロップだけ左へ90度回転
   ↓
正立状態としてOCR
```

重要なのは、**UI上のBBox自体を90度回転しているわけではない**ことです。

YOLO が検出した BBox は元画像上の位置・形状のまま表示し、その BBox から切り出した OCR 用画像だけを反時計回りに90度回転します。

Label ON 時は対象 nmb をオレンジ系で識別できます。

## 8. BBoxと読取方向表示

BBox は「どこを検出したか」、方向表示は「その領域をOCR時にどの向きへ補正しているか」を表します。

| 状態 | 意味 |
|---|---|
| 水色系 BBox | 回転補正なし |
| L 補正表示 | 左 Tube を180度補正してOCR |
| オレンジ系 Label BBox | nmb を左90度補正してOCR |

回転補正が有効な場合、対象となる最上段BBox付近に読取方向を示す矢印を表示します。矢印は検査対象文字を隠しにくい位置・透過表示を前提としています。

## 9. 端子番号と線番の照合

VisionLink では Label / nmb をアンカーとして左右の線番を対応付けます。

概念的には次のようになります。

```text
──────── 隣接Labelとの中間境界 ────────

        左側候補       右側候補
             \         /
              \       /
              [ Label ]  ← この端子の基準

──────── 隣接Labelとの中間境界 ────────
```

単純に「Labelのすぐ横だけ」を対象にするのではなく、隣接 Label との位置関係から行バンドを作り、その範囲内の左右候補を照合します。

この方式は、カメラ映像上で端子や線番の高さが多少ずれても同一端子として扱いつつ、隣接端子の線番まで誤って対応付けることを抑えるためのものです。

## 10. 検査結果の見方

検査画面では Label / nmb の OCR 結果も表示されます。

確認時は「検出できたか」だけでなく、次を確認してください。

- nmb が期待する端子番号として読めているか
- 左線番が正しい端子へ対応しているか
- 右線番が正しい端子へ対応しているか
- 回転補正が実物の向きと一致しているか
- 隣接端子の結果を誤って取り込んでいないか

## 11. うまく読めない場合

### nmb が横向き

数字が右へ90度倒れている場合は **Label を ON** にします。

### 左線番が逆さ

左 Tube の文字が上下逆の場合は **L を ON** にします。

### BBox は出るが文字を読めない

- カメラを少し近づける
- ピントを合わせる
- 反射を避ける
- 数秒静止する
- 文字全体が BBox 内に入っているか確認する

### 隣の線番が消し込まれる

Label が正しく検出されているか確認してください。Label が欠落すると端子ごとの行バンドを正しく構成できず、対応付け精度が低下する場合があります。

## 12. 注意事項

- 本版は **プロトタイプ** です。
- AI/OCR結果のみを根拠として製品品質を確定しないでください。
- BBox は検出領域であり、OCR時の画像回転そのものを示すものではありません。
- `L` は左 Tube の180度補正です。
- `Label` は右へ90度倒れた nmb を読むため、OCR用クロップを左へ90度補正します。
- 誤認識や誤対応を発見した場合は、対象画像・端子番号・期待値・実際のOCR結果を記録すると改善に利用しやすくなります。
