## 1. VisionLinkとは

VisionLink は、端子台・配線の検査を iPhone 等のカメラ画像と AI で支援する Web アプリケーションです。

カメラ画像から YOLO で検査対象を検出し、PaddleOCR で文字を読み取り、あらかじめ用意された CSV の検査データと照合します。

検査する1端子は次の3要素で構成します。

- **L**: 端子左側の Tube（線番）
- **Label / nmb**: 中央の端子番号
- **R**: 端子右側の Tube（線番）

VisionLinkは単に画面内に同じ文字列が存在するかを確認するのではなく、中央のLabel / nmbを基準として、その端子に属する左右Tubeを対応付けて検査します。

## 2. 検査対象と端子台の向き

### 2.1 1端子の位置関係

1端子についての物理的な位置関係は次のとおりです。

```text
左側                                     右側

 Tube（L） ───── 端子（Label / nmb） ───── Tube（R）
   線番                  端子番号                 線番
```

つまり、検査の基本単位は **「Tube ― 端子 ― Tube」** です。

### 2.2 端子台は縦向きに撮影する

実機検査では、端子台の長手方向がiPhone画面の上下方向になるように構えます。このとき画面内では、中央に端子番号（Label / nmb）が縦一列に並び、その左側にL Tube、右側にR Tubeが並びます。

```text
              iPhoneカメラ画面

        L             Label             R
     左Tube列         端子番号列        右Tube列

      AAAAA              6              AAAAA
      BBBBB              7              BBBBB
      CCCCC              8              CCCCC
      DDDDD              9              DDDDD
```

端子台を縦向きに撮影しても、1端子の対応関係は上下ではありません。**同じ高さにある L ― Label ― R が1組**です。

## 3. iPhone検査画面の構成

実機では Safari から VisionLink を開き、1画面の中で「カメラ映像」「回転補正」「検査操作」「検査テーブル」を確認しながら作業します。

### 3.1 カメラ映像と検出枠

画面上部はライブカメラ領域です。端子台全体を縦向きに収め、中央の端子番号列と左右のTube列を同時に撮影します。

カメラ映像上に重ねて表示されるBBox（Bounding Box）は、YOLOが検出した対象の**元画像上の位置**を示します。BBoxの位置と形状はOCRの回転補正とは独立しています。

したがって、`L` または `Label` をONにしても、画面上の端子やBBoxそのものが180度・90度回転するわけではありません。検出したBBox内部をOCR用画像として切り出した後、その**crop画像だけ**を必要な向きへ回転させてOCRへ渡します。

### 3.2 BBoxの色

BBoxの色は、現在どの読取方法を適用しているかを作業者が確認するための表示です。

| BBox表示 | 対象 | OCR時の処理 |
|---|---|---|
| 水色系 | 通常読取対象 | 回転なし |
| 紫系 | L Tube | OCR用cropを180度回転 |
| オレンジ系 | Label / nmb | OCR用cropを左へ90度回転 |

色は検査対象の状態を視覚的に区別するためのもので、BBoxの座標系を変更するものではありません。

### 3.3 L / Label ボタン

カメラ領域の下にはOCR方向を補正するボタンがあります。

**L** は左Tube用です。左側Tubeの文字がカメラ画像上で逆さになっている場合にONにします。ON時は左TubeのOCR用cropを180度回転してからOCRします。ボタンの状態は色で表し、画面を大きく動かすような表示変更は行いません。

**Label** は中央の端子番号用です。端子台を縦向きにした結果、nmbの数字が画面上で右へ90度倒れている場合にONにします。ON時はnmbのOCR用cropを左へ90度回転し、数字を正立させてOCRします。Label対象のBBoxはオレンジ系で表示されます。

### 3.4 カメラ開始 / 停止

`カメラ開始` でライブ映像を開始します。撮影中は端子台が画面内に収まり、中央Label列と左右Tube列のBBoxが安定して表示される位置へiPhoneを調整します。

カメラを停止しても、それまでの検査結果の意味が変わるわけではありません。撮影状態と検査結果は区別して扱います。

### 3.5 検査開始 / 停止

`検査開始` でOCRと照合を開始します。検査中は検出・OCR結果が更新され、CSVの期待値と一致した項目が下部の検査テーブルへ反映されます。

`検査停止` は検査処理を止めるための操作です。カメラ自体の開始・停止とは別の操作です。

### 3.6 検査対象の選択

検査テーブル上部の選択欄では、検査対象となる製番・盤等の番号・端子台を選択します。画面例では製番、番号、端子台名が横並びで表示されます。

`再読込` は対象データを読み直す際に使用します。検査対象を変更した場合は、現在表示している検査テーブルが意図した製番・端子台であることを確認してから検査を開始してください。

### 3.7 進捗表示

`9 / 100` のような表示は、現在の消込進捗を示します。左側が完了数、右側が検査対象総数です。

この数値だけで合否を判断せず、下の `L / Label / R / ALL` の各状態も確認してください。

### 3.8 検査テーブル

検査結果は1端子を1行として、次の4列で表示します。

| 列 | 表示内容 |
|---|---|
| `L` | 左Tubeの線番と照合状態 |
| `Label` | 中央の端子番号と照合状態 |
| `R` | 右Tubeの線番と照合状態 |
| `ALL` | その端子全体の完了状態 |

一致した項目は緑表示になります。例えばLabelとRだけが認識済みでLが未認識の場合、LabelとRだけが先に緑になり、Lは未完了のまま残ります。この状態では1端子すべての確認が終わったとは扱いません。

### 3.9 作業者確認と完了

画面下部の `作業者確認` は、AI/OCRによる自動照合とは別に、作業者が検査内容を確認したことを扱うための項目です。

`完了` を押す前に、進捗だけでなく未消込行が残っていないか、読み違いがないか、対象の製番・端子台が正しいかを確認してください。

## 4. 検査前の準備

1. iPhoneを社内LAN/Wi-Fiへ接続します。
2. SafariからVisionLinkを開きます。
3. 製番・盤・端子台を選択し、検査CSVを読み込みます。
4. 端子台を縦向きにしてカメラへ収めます。
5. 中央のLabel列と、その左右のTube列が同時に映る位置へ調整します。
6. 必要に応じて `L` / `Label` の回転補正を設定します。

照明の反射、ピンぼけ、極端な斜め撮影はOCR精度を低下させます。特にLabel列は左右Tubeの対応付けの基準になるため、中央の端子番号が安定して検出できる位置を優先してください。

## 5. 基本的な検査手順

1. **カメラ開始** を押します。
2. 端子台を縦向きに映します。
3. 中央の端子番号と左右TubeにBBoxが表示されることを確認します。
4. 左Tubeが逆さなら **L**、nmbが右へ90度倒れていれば **Label** をONにします。
5. BBoxの色と読取方向表示が意図した状態になっていることを確認します。
6. **検査開始** を押します。
7. カメラを短時間安定させてOCRさせます。
8. 下部の検査テーブルで `L / Label / R / ALL` を確認します。
9. 未検査箇所がある場合は、端子台との距離と角度を保ちながらカメラ位置をゆっくり移動します。
10. 全対象の消込後、必要に応じて **作業者確認** をチェックします。
11. **完了** で検査を終了します。

## 6. L ボタン

`L` は左TubeのOCR方向補正です。

### OFF

左Tubeのクロップ画像をそのままOCRします。

### ON

- 左TubeのOCR用cropだけを**180度回転**します。
- カメラ映像そのものは回転しません。
- BBoxの位置・形状も回転しません。
- L補正対象は紫系の表示で識別します。

左Tubeの文字が逆さになっている場合に使用します。

## 7. Label ボタン

`Label` は中央の端子番号（nmb）のOCR方向補正です。

端子台を縦向きに撮影した際、nmbの数字が画面上で**右へ90度倒れている**場合に使用します。

```text
画面上のnmb
   ↓
右へ90度倒れている
   ↓
BBox領域をcrop
   ↓
OCR用cropだけ左へ90度回転
   ↓
正立した数字としてOCR
```

ON時はLabelボタンとnmbのBBoxをオレンジ系で表示します。

重要なのは、**オレンジのBBoxそのものを回転しているわけではない**ことです。BBoxは元カメラ画像上の検出位置・形状のままで、OCRへ渡すcrop画像だけを回転します。

## 8. BBoxと読取方向表示

回転補正が有効な場合は、対象となる最上段BBoxの枠外左上付近に、OCRでどの向きへ読ませているかを示す矢印を表示します。

矢印はBBoxと同系色とし、検査対象の文字やBBoxを隠しにくい大きさ・透過表示とします。

この矢印も「BBoxを回転させた」という意味ではありません。**OCR用cropに適用している読取方向**を作業者へ示すための表示です。

## 9. 端子番号と線番の照合

VisionLinkは中央のLabel / nmbをアンカーとして、その端子に対応する左右Tubeを探します。

```text
            左Tube       Label       右Tube

端子6       H0D4F8V        6         H0D4F8V
端子7       P5X9Q2         7         P5X9Q2
端子8       D5A2L9F4       8         D5A2L9F4
端子9       V2C8M          9         V2C8M
```

### 端子ごとの検査範囲

隣接するLabelの中心位置の中間を境界として、各端子の検査範囲を分けます。

```text
──── Label 5 と Label 6 の中間 ────

   左Tube       [ Label 6 ]       右Tube

──── Label 6 と Label 7 の中間 ────

   左Tube       [ Label 7 ]       右Tube

──── Label 7 と Label 8 の中間 ────
```

その範囲内にあり、かつLabelより左側にあるTubeをL候補、右側にあるTubeをR候補としてCSVと照合します。

この方式は「画面のどこかに同じ線番があればOK」とするものではありません。**どの端子番号の左右に存在するTubeなのか**を含めて対応付けることで、隣接端子の線番を誤って別端子へ消し込むことを抑えます。

## 10. 検査テーブルの見方

### OK

対象端子について必要な `L / Label / R` の照合が成立すると、その端子の `ALL` が `OK` になります。

### 一部だけ認識された場合

認識・照合できた項目だけ先に緑表示され、未認識の項目は残ります。

例えば、端子番号7と右Tube `P5X9Q2` が読めても左Tubeがまだ読めていない場合、LabelとRだけが消し込まれ、Lおよび端子全体は未完了として残ります。

### nmb結果の確認

中央Labelは単なる飾りではなく、OCRした端子番号の結果を検査テーブル上でも確認します。端子番号の認識が左右Tubeの対応付けの基準になるため、誤った番号が表示されていないか確認してください。

## 11. うまく読めない場合

### 端子番号が読めない

- 端子台が縦向きになっているか確認する
- nmbが右へ90度倒れて見える場合は **LabelをON**
- 中央Label列全体がカメラ内に入るよう調整する
- ピントと照明を調整する

### 左Tubeが読めない

左Tube文字が逆さの場合は **LをON** にします。ONにしてもBBoxが回転しないことは正常です。

### BBoxは出るがOCRされない

- カメラを少し近づける
- 数秒静止する
- 反射を避ける
- 文字全体がBBox内に入っているか確認する
- L / Labelの回転設定が実物の文字方向と合っているか確認する

### 隣の端子の線番を拾う

中央のLabel列が正しく検出されているか確認してください。VisionLinkはLabel位置から各端子の検査帯を決めるため、Labelの検出状態が対応付け精度に影響します。

## 12. 注意事項

- 本版は **Prototype** です。
- 端子台は基本的に **縦向きで読み込みます**。
- 1端子の物理的な関係は **Tube ― 端子 ― Tube** です。
- 画面上の対応関係は **L ― Label ― R** です。
- `L` は左TubeのOCR用cropを180度補正します。
- `Label` は右へ90度倒れたnmbを読むため、OCR用cropを左へ90度補正します。
- **L / LabelをONにしてもBBoxそのものは回転しません。**
- 検査画面は、状態更新によって操作位置が大きく変化しないよう固定的なレイアウトを前提としています。
- AI/OCR結果のみを根拠として製品品質を確定しないでください。
- 誤認識を発見した場合は、対象端子・期待値・実際のOCR結果・可能であれば画像を記録してください。
