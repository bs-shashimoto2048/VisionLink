# VisionLink ユーザーガイド（Prototype）

VisionLink の検査担当者向け操作マニュアルです。本書は、初めて使用する作業者が **端子台の置き方 → カメラ開始 → OCR向きの設定 → 検査開始 → 消込確認 → 完了** まで実施できることを目的としています。

> **対象版**: 2026-08-24 時点の実機確認済み Prototype  
> **重要**: 画像は実際の画面を理解するための補助です。操作方法・判定条件は本文を基準にしてください。

## 2. 何を検査するか

### 2.1 1端子の基本構成

1端子は横方向に次の3要素で構成されます。

```text
左側                                              右側

Tube（L） ───── 端子（Label / nmb） ───── Tube（R）
  線番                  端子番号                  線番
```

**基本は「Tube ― 端子 ― Tube」です。**

- `L` : 端子左側のTubeに印字された線番
- `Label / nmb` : 中央の端子番号
- `R` : 端子右側のTubeに印字された線番

VisionLinkは、画面内のどこかに同じ文字列があるだけではOKにしません。中央の端子番号を基準として、その端子の左側と右側にあるTubeを対応付けます。

### 2.2 端子台は縦向きに撮影する

実機検査では、端子台の長手方向がiPhone画面の上下方向になるように構えます。

```text
        iPhone画面

左Tube列   Label列   右Tube列

H0D4F8V       6       H0D4F8V
P5X9Q2        7       P5X9Q2
D5A2L9F4      8       D5A2L9F4
V2C8M         9       V2C8M
```

端子台を縦向きにしても、対応関係は上下ではありません。**同じ高さの L ― Label ― R が1端子です。**

## 3. 検査前の準備

検査を開始する前に次を確認します。

1. iPhoneを使用するネットワークへ接続します。
2. SafariでVisionLinkを開きます。
3. 製番を選択します。
4. 盤・番号を選択します。
5. 端子台を選択します。
6. 検査テーブルに意図したCSVデータが表示されていることを確認します。
7. `カメラ開始` を押します。
8. 端子台を縦向きに映します。
9. 中央Label列と左右Tube列が同時に見える位置へ調整します。

### 良い撮影状態

- Label列が中央付近に連続して見える
- 左右Tubeの文字全体が見える
- ピントが合っている
- 強い反射がない
- 端子台が極端に斜めでない
- BBoxが対象文字をほぼ覆っている

### 避ける状態

- Label列が画面外へ切れている
- 左右どちらかのTube列が見えない
- 文字が小さすぎる
- カメラが近すぎて文字が切れる
- 強い反射で印字が白飛びしている
- iPhoneを動かし続けている

## 4. OCR方向補正

VisionLinkでは、**カメラ画像やBBoxを回転させるのではなく、BBoxから切り出したOCR用cropだけを回転**します。

### 4.1 `L` ボタン

左Tubeの文字が逆さの場合に使用します。

`L` ON時:

```text
左Tubeを検出
   ↓
BBox内部をcrop
   ↓
OCR用cropだけ180°回転
   ↓
OCR
```

| 対象 | L ON時 |
|---|---|
| カメラ映像 | 回転しない |
| BBox | 回転しない |
| OCR用crop | 180°回転する |

左Tubeが正立している場合はOFFのまま使用してください。

### 4.2 `Label` ボタン

端子台を縦向きにした結果、端子番号が画面上で**右へ90°倒れている**場合に使用します。

`Label` ON時:

```text
右へ90°倒れたnmb
   ↓
BBox内部をcrop
   ↓
OCR用cropだけ左へ90°回転
   ↓
数字を正立
   ↓
OCR
```

| 対象 | Label ON時 |
|---|---|
| カメラ映像 | 回転しない |
| オレンジBBox | 回転しない |
| BBox座標 | 変わらない |
| OCR用crop | 左へ90°回転する |

---

## 5. BBoxの見方

BBoxはYOLOが検出した対象領域です。**BBoxが表示されたことと、OCRが正しく読めたことは別です。**

| 表示色 | 対象・意味 |
|---|---|
| 紫系 | L Tube / 180°補正対象 |
| オレンジ系 | Label / nmb / 90°補正対象 |
| 水色系 | 通常読取対象 / 主にR Tube |

回転補正中に表示される方向矢印も、BBoxの回転を表すものではありません。OCR用cropに適用している読取方向を示します。

BBoxを見るときは、対象文字全体が枠内に入っているか確認してください。文字の一部しか入っていない場合や隣のTubeまで大きく囲っている場合は、カメラ位置を調整します。

---

## 6. 検査開始から完了まで

### Step 1 — 対象を確認

製番・盤番号・端子台が実物と一致していることを確認します。

### Step 2 — カメラ開始

`カメラ開始` を押します。端子台を縦向きに映します。

### Step 3 — BBox確認

左Tube、中央Label、右TubeにBBoxが出ていることを確認します。

### Step 4 — 回転設定

- 左Tubeが逆さ → `L` ON
- nmbが右90°倒れ → `Label` ON

### Step 5 — 検査開始

`検査開始` を押します。OCR中はiPhoneを短時間安定させます。

### Step 6 — 消込確認

検査テーブルの `L / Label / R / ALL` を確認します。

### Step 7 — 未完了箇所を読む

未完了端子がある場合は、距離と角度を大きく変えずにカメラをゆっくり移動します。

### Step 8 — NG確認

NGがある場合は、OCR誤読か実物不一致かを切り分けます。

### Step 9 — 完了

未完了・NGがないことを確認し、必要に応じて `作業者確認` をチェックして `完了` を押します。

---

## 7. 端子番号を基準にした左右Tubeの検査

VisionLinkではLabel / nmbをアンカーにします。

```text
左Tube       Label       右Tube

H0D4F8V        6         H0D4F8V
P5X9Q2         7         P5X9Q2
D5A2L9F4       8         D5A2L9F4
V2C8M          9         V2C8M
```

隣接するLabel同士の中心位置の中間を、各端子の縦方向の境界として使用します。

```text
──── Label 5 / 6 の中間 ────

 左Tube      [ Label 6 ]      右Tube

──── Label 6 / 7 の中間 ────

 左Tube      [ Label 7 ]      右Tube

──── Label 7 / 8 の中間 ────
```

同じ端子帯の中でLabelより左側にあるTubeをL候補、右側にあるTubeをR候補としてCSVと照合します。

このため、別端子に同じ線番が存在していても、単純な文字列一致だけで消し込む方式ではありません。

## 8. 検査テーブルの見方

| 列 | 意味 |
|---|---|
| `L` | 左TubeのOCR・照合結果 |
| `Label` | 端子番号のOCR・照合結果 |
| `R` | 右TubeのOCR・照合結果 |
| `ALL` | 1端子全体の完了状態 |

### 緑

CSV期待値と一致した項目です。

### 赤 / NG

期待値と一致しない状態です。

### 未表示・通常表示

まだ検査が成立していない、または未確定の状態です。

### 一部だけ緑の場合

たとえばLabelとRだけ一致してLが未認識の場合、LabelとRだけ先に緑になります。**その端子全体はまだ完了ではありません。**

---

## 9. OK・NG・未完了の判断

### OK

対象端子について必要なL・Label・Rが期待値と対応し、端子全体の照合が成立した状態です。

### NG

OCR結果とCSV期待値が一致しない状態です。

NG表示だけで直ちに製品不良と断定せず、次の順で確認してください。

1. Label番号が正しく読めているか
2. LのOCR結果
3. RのOCR結果
4. L / Labelの回転設定
5. BBox位置
6. CSV期待値
7. 実物印字

### 未完了

まだ必要なOCR・照合が成立していない状態です。NGとは異なります。

---

## 10. うまく読めない場合

### Labelが読めない

- 数字が右90°倒れているなら `Label` をON
- Label列を画面中央付近へ移動
- 数字全体がBBox内にあるか確認
- 反射とピントを確認

### 左Tubeが読めない

- 逆さなら `L` ON
- 正立なら `L` OFF
- 線番全体がBBox内にあるか確認

### 右Tubeが読めない

右Tubeは通常回転させません。撮影角度、距離、ピント、反射を確認します。

### BBoxは出るがOCRされない

BBox検出とOCRは別処理です。文字サイズ、ブレ、BBox範囲、OCR方向を確認します。

### 隣の端子を拾うように見える

中央Label列の検出状態を最初に確認します。Label位置が端子ごとの左右Tube探索範囲の基準です。

---

## 11. 検査終了前チェック

`完了` を押す前に確認してください。

- [ ] 製番が正しい
- [ ] 盤・番号が正しい
- [ ] 端子台が正しい
- [ ] 未完了行が残っていない
- [ ] NG行を確認した
- [ ] Labelの誤読がない
- [ ] L / Rの線番が期待値と一致している
- [ ] 必要に応じて作業者確認を行った

## 12. よくある質問

**Q. Label ONにするとBBoxも90°回転しますか？**  
A. しません。OCR用cropだけを左90°回転します。

**Q. L ONにすると画面全体が180°回転しますか？**  
A. しません。左TubeのOCR用cropだけです。

**Q. BBoxの色はOK/NGですか？**  
A. いいえ。主に対象種類・OCR補正状態を示します。合否は検査テーブルで確認します。

**Q. Labelだけ読めれば端子は完了ですか？**  
A. いいえ。左右Tubeを含む必要な照合が成立する必要があります。

**Q. NGが出たら即不良ですか？**  
A. OCR誤読の可能性もあるため、BBox、OCR方向、CSV、実物を確認してください。

## 13. Prototypeとしての注意

- 端子台は基本的に縦向きで読み込みます。
- 1端子の物理関係は **Tube ― 端子 ― Tube** です。
- 画面上の検査関係は **L ― Label ― R** です。
- `L` は左TubeのOCR用cropを180°補正します。
- `Label` は右90°倒れたnmbのOCR用cropを左90°補正します。
- `L / Label` をONにしてもBBox自体は回転しません。
- AI/OCR結果だけで最終品質を確定しないでください。

## 14. 用語集

| 用語 | 意味 |
|---|---|
| Tube | 端子に接続された電線のチューブ。線番が印字されている |
| L | 端子左側のTube |
| R | 端子右側のTube |
| Label / nmb | 端子番号 |
| BBox | YOLOが検出した対象領域を示す枠 |
| OCR | 画像から文字を読み取る処理 |
| crop | BBox内部から切り出したOCR用画像 |
| CSV | 登録された検査期待データ |
| 消込 | OCR結果と期待値が一致した項目を検査済みとして反映すること |
| ALL | 1端子として必要な検査が揃った状態 |
