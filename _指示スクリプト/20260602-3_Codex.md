検査APPとして重要な仕様を追加・修正してください。

現在、検査テーブルを inspection.detections と ocr_results から再照合して表示する実装になっていますが、検査は「消し込み方式」で行います。

重要仕様:
- OKになった値は保持し続ける
- NGや不一致は一時情報として扱い、保持しない
- NGのまま終了させない
- 検出できないフレームがあっても、過去にOKになったセルをPENDINGへ戻さない
- 再検査してOKになるまで検査を続ける

修正してください。

1. reconcileCheckRows() は既存の checkRows 状態をベースに更新してください。
   毎回CSV初期状態や検出結果だけから作り直さないでください。

   例:
   const updatedRows = previousRows.map(row => ({ ...row }));

2. 既に OK のセルは上書きしないでください。

   対象:
   - tube_l_status === "OK"
   - tube_r_status === "OK"
   - label_status === "OK"
   - all_status === "OK"
   - completed === true

   例:
   if (row.tube_l_status === "OK") {
     // 既に消込済みなので変更しない
   }

3. Tube_L / Tube_R の照合で不一致だった場合、NGを保持しないでください。

   現時点の仕様:
   - NGは一時的な検出結果として扱う
   - row.tube_l_status = "NG" のように永続セットしない
   - 必要であれば console.debug には mismatch として出す
   - UIにも恒久的な赤表示はしない

4. 不一致または未検出の場合は、既存状態を維持してください。

   例:
   - 以前OKならOKのまま
   - 以前PENDINGならPENDINGのまま
   - NGとして固定しない

5. OKになった場合だけ状態を進めてください。

   Tube_L一致:
   - tube_l_status = "OK"

   Tube_R一致:
   - tube_r_status = "OK"

   Tube_L と Tube_R が両方OK:
   - label_status = "OK"
   - all_status = "OK"
   - confirm_status = "OK"
   - completed = true
   - 行背景グレー
   - Tube_L / Label / Tube_R を緑文字

6. completed === true の行は、その後の照合で変更しないでください。

   例:
   if (row.completed || row.all_status === "OK") {
     return row;
   }

   ただし表示は保持してください。
   - Tube_L 緑
   - Label 緑
   - Tube_R 緑
   - 行背景グレー
   - ALL☑ OK
   - ✔ ◯

7. 全行完了判定は completed または all_status === "OK" の行のみで行ってください。

   例:
   const allRowsCompleted =
     checkRows.length > 0 &&
     checkRows.every(row => row.completed || row.all_status === "OK");

8. 作業者確認チェックは、全行完了するまで disabled のままにしてください。

   全行完了前:
   - workerConfirmed = false
   - チェック不可

   全行完了後:
   - チェック可能

9. [完了] ボタンは以下を満たすまで disabled にしてください。

   - 全行完了
   - workerConfirmed === true

   NGやPENDINGが1つでも残っている場合は完了不可です。

10. 検査テーブルを切り替えた場合だけ、検査状態をリセットしてください。

   リセット条件:
   - selectedSerial が変わった
   - selectedBoard が変わった
   - selectedTerminal が変わった
   - CSVを再読み込みした

   リセットしてよいもの:
   - tube_l_status
   - tube_r_status
   - label_status
   - all_status
   - completed
   - workerConfirmed

11. 検査停止・カメラ停止では、OK済みの消込状態を消さないでください。

   理由:
   - 一時停止やカメラ停止後に再開しても、既にOKになった検査結果は保持する必要があるため

12. 検査開始を押した後、frame-analyze response ごとに reconcileCheckRows() を実行する場合も、previousRows を使って累積更新してください。

   例:
   setCheckRows(prevRows =>
     reconcileCheckRows({
       rows: prevRows,
       yoloResults: response.yolo_results,
       ocrResults: response.ocr_results,
       guideX: 0.5,
     })
   );

   - TypeScript エラーなし
   - 一度OKになった Tube_L は、次フレームで検出されなくても緑のまま
